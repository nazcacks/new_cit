# CIT 운영 매뉴얼 v1.0

## 기동

```powershell
docker compose up --build -d postgres api
```

## 상태 점검

```powershell
Invoke-RestMethod http://localhost:8080/health
Invoke-RestMethod http://localhost:8080/ready
```

- `/health`: 프로세스 생존 확인
- `/ready`: DB 연결까지 포함한 준비 상태 확인

## 정기 점검

- `docker compose run --rm test bash -lc "/usr/local/cargo/bin/cargo test --all --all-targets"`
- `docker compose run --rm clippy`
- `node --check frontend\app.js`
- `git diff --check`

## 감사/알림 운영

- 감사 로그: `/api/tenants/{tenant_code}/audit-logs`
- 알림 센터: `/api/tenants/{tenant_code}/notifications`
- 대시보드: `/api/tenants/{tenant_code}/dashboard`
- 사업연도 마감 D-30 알림은 대시보드/알림 센터 조회 시 자동 보강된다.

## 장애 대응

1. `/health`, `/ready`로 장애 범위를 구분한다.
2. DB 장애면 PostgreSQL 컨테이너 상태와 마이그레이션 로그를 확인한다.
3. API 장애면 `docker compose logs api`로 panic, migration, port 충돌을 확인한다.
4. 신고 파일 생성 실패는 job 상태와 dead-letter queue를 확인하고 필요 시 retry API를 사용한다.
