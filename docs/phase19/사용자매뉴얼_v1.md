# CIT 사용자 매뉴얼 v1.0

## 로그인

- 테넌트 코드, 로그인 ID, 비밀번호를 입력한다.
- 개발 데모 계정은 `demo / admin / ChangeMe123!`이다.

## 사용자/권한 관리

- `관리 > 사용자 관리`에서 사용자 목록, 신규 등록, 편집, 잠금, 2FA 리셋을 수행한다.
- 사용자 접근범위는 테넌트, 고객사, 고객사별 업무범위 순서로 지정한다.
- 고객사에 허용되지 않은 대상 업무는 사용자에게 부여할 수 없다.

## 신고 작업

1. 고객사와 사업연도를 선택한다.
2. 세무정보를 입력하거나 CSV/XLSX로 업로드한다.
3. B-1~B-17 세무조정을 수행한다.
4. 서식을 생성하고 미리보기/수정/검증을 확인한다.
5. 결재 후 신고 상태로 전환한다.
6. PDF/ZIP 출력 또는 전자신고 파일 생성을 수행한다.

## 분석/운영

- 운영 대시보드: 고객사, 사업연도, 마감 D-30, 미확인 알림, 감사 로그 요약
- 알림 센터: 사업연도 마감, 검토 요청 등 인앱 알림
- 세부담 분석: 과세표준, 납부세액, 실효세율
- 연도 비교: 고객사별 사업연도 상태, 조정 합계, 유보 건수
- 감사 로그: 변경 행위, 대상, 작업자, 해시 체인
