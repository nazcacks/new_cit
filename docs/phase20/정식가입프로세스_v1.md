# Phase 20 정식 가입 프로세스 v1.0

## 가입 대상

- 회계법인
- 세무법인
- 세무사사무소

## 절차

1. 가입 신청 접수
2. 계약/사업자등록번호 확인
3. 테넌트 코드 확정
4. 테넌트 생성
5. 최초 관리자 계정 초대
6. 고객사 등록 및 고객사별 대상 업무 설정
7. 사용자별 고객사/업무권한 부여
8. 첫 사업연도 생성 및 법령/서식/전자신고 스냅샷 확인
9. 교육 자료 전달 및 운영 시작

## 필수 확인

- 테넌트는 고객사를 1:N으로 관리한다.
- 사용자 권한은 테넌트, 고객사, 고객사별 대상 업무, 사용자별 부여 업무, 역할 권한 순서로 제한된다.
- 고객사별 대상 업무가 다르면 사용자별 부여 업무도 고객사별로 다르게 설정한다.
